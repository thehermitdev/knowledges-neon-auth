# Project Overview

- **Type:** แปลภาษาจากอังกฤษเป็นภาษาไทยจากเอกสาร
- **Stack:** Neon Auth

# Instruction

1. อ่าน AGENTS.md และ SKILL.md ก่อนทุกครั้ง
2. ทำความเข้าใจเอกสารที่ผู้ใช้งานบอกผ่านไฟล์ .md จาก Github
3. ดำเนินการแปลจากภาษาอังกฤษเป็นภาษาไทย**อย่างละเอียด** โดยไม่ต้องรอการยืนยัน
4. ทำการ commit เข้า main ทันที
5. รอไฟล์ถัดไปจากผู้ใช้งาน แล้วกลับไปข้อที่ 1

# DO

- ให้ใช้ภาษาที่อ่านง่ายแต่ยังคงความเป็นมืออาชีพอยู่
- ให้ใช้คำทับศัพท์มากกว่าการวงเล็บคำ เช่น
  | ✅ ผ่าน | 🚫 หลีกเลี่ยง |
  | ---------- | ----------------------- |
  | คอมโพเนนต์ | Components (คอมโพเนนต์) หรือ คอมโพเนนต์ (Components) |
  | เมจิกลิงก์ | Magic Link (ลิงก์วิเศษ) หรือ ลิงก์วิเศษ (Magic Link) |
  | เว็บฮุก | Webhooks (ตัวดึงหน้าเว็บ) หรือ เว็บฮุก (Webhooks) |
- หากเป็นศัพท์ประเภทเทคนิกระดับสูงแล้วคุณคิดว่ากำลังพยายามแต่งคำ ให้ใช้คำเป็นภาษาอังกฤษไปเลย

# DON'T

- ห้ามแปลแบบรวบลัดจนความหมายผิดเพี้ยน
- ห้ามใช้ ไทยคำ อังกฤษคำ จนอ่านยาก
- ห้ามแทรกอะไรก็ตามที่ไม่เคยมีอยู่ในไฟล์ต้นฉบับ เช่น ภาพ, คำแนะนำเพิ่มเติม, หรือ URL อื่นๆ
