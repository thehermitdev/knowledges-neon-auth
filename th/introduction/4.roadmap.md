# โรดแมปของ Managed Better Auth

สิ่งที่รองรับในปัจจุบันและสิ่งที่จะตามมา

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

Managed Better Auth อยู่ระหว่างการพัฒนาอย่างต่อเนื่อง หน้านี้แสดงสิ่งที่รองรับในปัจจุบันและสิ่งที่เรากำลังพัฒนาต่อไป

## การเปิดให้ใช้งานทั่วไป

Managed Better Auth ตั้งเป้าเปิดให้ใช้งานทั่วไปภายในไตรมาสนี้ เรากำลังพัฒนาปลั๊กอินและฟีเจอร์เพิ่มเติมอย่างต่อเนื่องเพื่อนำ Managed Better Auth ออกจากสถานะ Beta

## เฟรมเวิร์ก

### รองรับแล้ว

| เฟรมเวิร์ก              | สถานะ       | เริ่มต้นอย่างรวดเร็ว                                                    |
| ----------------------- | ----------- | --------------------------------------------------------------------- |
| Next.js                 | ✅ รองรับ    | [เริ่มต้นใช้งาน](https://neon.com/docs/auth/quick-start/nextjs-api-only) |
| Vite + React            | ✅ รองรับ    | [เริ่มต้นใช้งาน](https://neon.com/docs/auth/quick-start/react)           |
| React + React Router    | ✅ รองรับ    | [เริ่มต้นใช้งาน](https://neon.com/docs/auth/quick-start/react)           |
| React + TanStack Router | ✅ รองรับ    | [เริ่มต้นใช้งาน](https://neon.com/docs/auth/quick-start/tanstack-router) |

[คู่มือเริ่มต้น React](https://neon.com/docs/auth/quick-start/react) จะแนะนำขั้นตอนผ่านแอป **Vite** + React หากคุณใช้ **React Router** สำหรับ URL และเลย์เอาต์ ให้ใช้ Managed Better Auth URL, client `@neondatabase/neon-js` และการเรียก SDK แบบเดียวกับในคู่มือนั้น แล้วผสานส่วนเหล่านี้เข้ากับ router และ route components ของคุณ สำหรับการทำ file-based routing ด้วย TanStack ให้ใช้คู่มือเริ่มต้น TanStack Router แทน

### อยู่ในโรดแมป

| เฟรมเวิร์ก                      | สถานะ                   |
| ----------------------------- | --------------- |
| Frontend + backend แบบแยกส่วน | 🔜 เร็วๆ นี้              |
| เฟรมเวิร์กอื่นๆ                  | ขึ้นอยู่กับความต้องการ      |

**หมายเหตุ: สถาปัตยกรรมแบบแยกส่วน**

สถาปัตยกรรมที่ frontend และ backend ถูก deploy แยกจากกัน (ตัวอย่างเช่น Create-React-App ที่ใช้ Node/Express backend แยกต่างหาก) ยังไม่รองรับในขณะนี้ Managed Better Auth ใช้คุกกี้ HTTP-only เพื่อจัดการเซสชันอย่างปลอดภัย และคุกกี้เหล่านี้ไม่สามารถแชร์ระหว่างแอปพลิเคชัน frontend และ backend ที่อยู่คนละโดเมนได้อย่างปลอดภัย เรากำลังพัฒนาการรองรับรูปแบบนี้อยู่

## ปลั๊กอิน Better Auth

Managed Better Auth สร้างบน [Better Auth](https://www.better-auth.com/) ปัจจุบันยังไม่รองรับปลั๊กอิน Better Auth ทุกตัว

### รองรับแล้ว

| ปลั๊กอิน                                                                            | สถานะ       |
| ---------------------------------------------------------------------------------- | ----------- |
| [อีเมลและรหัสผ่าน](https://www.better-auth.com/docs/authentication/email-password) | ✅ รองรับ    |
| Social OAuth (Google, GitHub, Vercel)                                              | ✅ รองรับ    |
| [Email OTP](https://neon.com/docs/auth/guides/plugins/email-otp)                   | ✅ รองรับ    |
| [Admin](https://neon.com/docs/auth/guides/plugins/admin)                           | ✅ รองรับ    |
| [Organization](https://neon.com/docs/auth/guides/plugins/organization)             | ⚠️ บางส่วน   |
| [JWT](https://neon.com/docs/auth/guides/plugins/jwt)                               | ✅ รองรับ    |
| [เมจิกลิงก์](https://neon.com/docs/auth/guides/plugins/magic-link)                 | ✅ รองรับ    |
| [Open API](https://neon.com/docs/auth/guides/plugins/openapi)                      | ✅ รองรับ    |
| [Phone Number](https://neon.com/docs/auth/guides/plugins/phone-number)             | ✅ รองรับ    |

ดู [การตั้งค่า OAuth](https://neon.com/docs/auth/guides/setup-oauth) สำหรับการตั้งค่า OAuth เฉพาะของ Neon (รวมถึง Vercel) ส่วนโฟลว์อีเมล เช่น การยืนยันและการรีเซ็ตรหัสผ่าน มีอธิบายไว้ใน [การยืนยันอีเมล](https://neon.com/docs/auth/guides/email-verification), [การรีเซ็ตรหัสผ่าน](https://neon.com/docs/auth/guides/password-reset) และ [การจัดการผู้ใช้](https://neon.com/docs/auth/guides/user-management)

### แพลตฟอร์ม (Console, API, เว็บฮุก)

ความสามารถเหล่านี้มีเอกสารอธิบายอยู่ในคู่มือ Managed Better Auth แต่ไม่ใช่ปลั๊กอิน Better Auth ที่คุณเปิดใช้งานผ่าน SDK

| ความสามารถ                            | สถานะ     | เอกสาร                                                                                       |
| ------------------------------------ | --------- | -------------------------------------------------------------------------------------------- |
| Trusted domains (redirect allowlist) | รองรับ     | [ตั้งค่า trusted domains](https://neon.com/docs/auth/guides/configure-domains)             |
| เว็บฮุก (auth events)                 | รองรับ     | [เว็บฮุก](https://neon.com/docs/auth/guides/webhooks)                                       |
| จัดการ Auth ผ่าน Neon API            | รองรับ     | [จัดการ Auth ใน Neon API](https://neon.com/docs/auth/guides/manage-auth-api)             |
| จัดการ Auth ผ่าน Neon MCP (AI editor) | รองรับ     | [ตั้งค่าด้วย AI editor ของคุณ](https://neon.com/docs/auth/overview#set-up-with-your-ai-editor) |

รองรับ auth ที่รับรู้บรานช์ (แต่ละบรานช์ Neon มี auth state แยกจากกัน) ดูรายละเอียดได้ที่ [การยืนยันตัวตนแบบแตกบรานช์](https://neon.com/docs/auth/branching-authentication) และ [โฟลว์การยืนยันตัวตน](https://neon.com/docs/auth/authentication-flow)

### อยู่ในโรดแมป
