# ใช้ Managed Better Auth กับ React (เมธอด API)

สร้าง UI การยืนยันตัวตนของคุณเอง

รัน `npx neon@latest init` เพื่อเชื่อมต่อ [Neon MCP server](https://neon.com/docs/ai/neon-mcp-server) และ [Agent Skills](https://neon.com/docs/ai/agent-skills) สำหรับ Managed Better Auth ดู [ตั้งค่าด้วย AI editor ของคุณ](https://neon.com/docs/auth/overview#set-up-with-your-ai-editor) สำหรับเครื่องมือ MCP, ตัวอย่างพรอมต์ และวิธีที่ skills ช่วยเชื่อมการยืนยันตัวตนเข้ากับแอปของคุณ

## สร้างโปรเจ็กต์ Neon ที่เปิดใช้งาน Auth

หากคุณยังไม่มีโปรเจ็กต์ Neon ให้สร้างโปรเจ็กต์ที่ [console.neon.tech](https://console.neon.tech)

ไปที่หน้า **Auth** ในแดชบอร์ดโปรเจ็กต์ แล้วคลิก **Enable Auth**

จากนั้นคุณจะพบ **Base URL** ของ Auth ในแท็บ Configuration ให้คัดลอก URL นี้ไว้ เพราะจะต้องใช้ในขั้นตอนถัดไป

## สร้างแอป React

สร้างแอป React ด้วย Vite

```bash filename="Terminal"
npm create vite@latest my-app -- --template react
```

## ติดตั้ง Neon SDK

Neon SDK มีเมธอดสำหรับการยืนยันตัวตน เช่น `signUp()`, `getSession()` และ `signOut()` สำหรับแอป React ของคุณ

```bash filename="Terminal"
cd my-app
npm install @neondatabase/neon-js@latest
```

## ตั้งค่า environment variables

สร้างไฟล์ `.env` ที่รูทของโปรเจ็กต์ แล้วเพิ่ม Auth Base URL ของคุณ:

**หมายเหตุ:** แทนที่ URL ด้วย Auth Base URL จริงจาก Neon Console

```bash filename=".env"
VITE_NEON_AUTH_URL=https://ep-xxx.neonauth.us-east-2.aws.neon.build/neondb/auth
```

## ตั้งค่า Neon client

สร้างไฟล์ `src/auth.js` เพื่อตั้งค่า auth client ของคุณ:

**เคล็ดลับ: ใช้ Auth และ Data API ร่วมกันอยู่หรือไม่?**

Quick Start นี้ใช้ Auth client แบบ standalone หากต้องการใช้ `createClient()` เพียง instance เดียวที่สร้างทั้ง Auth และ Data API URL จาก Neon URL เดียว โปรดดู [การเริ่มต้น `createClient()`](https://neon.com/docs/reference/javascript-sdk#initializing)

```javascript filename="src/auth.js"
import { createAuthClient } from '@neondatabase/neon-js/auth';

export const authClient = createAuthClient(import.meta.env.VITE_NEON_AUTH_URL);
```

## สร้าง UI การยืนยันตัวตนของคุณ

Neon JS ใช้แนวทางแบบโปรแกรมในการจัดการ auth state คุณจะใช้ React hooks เช่น `useEffect` เพื่อตรวจสอบเซสชันและจัดการการเปลี่ยนแปลงด้านการยืนยันตัวตน

แทนที่เนื้อหาของ `src/App.jsx` ด้วยโค้ดต่อไปนี้เพื่อใช้งาน [การสมัครสมาชิก](https://neon.com/docs/reference/javascript-sdk#auth-signup), [การเข้าสู่ระบบ](https://neon.com/docs/reference/javascript-sdk#auth-signinwithpassword) และ [การออกจากระบบ](https://neon.com/docs/reference/javascript-sdk#auth-signout):

```jsx filename="src/App.jsx"
import { useState, useEffect } from 'react';
import { authClient } from './auth';
import './App.css';

export default function App() {
  const [session, setSession] = useState(null);
  const [user, setUser] = useState(null);
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [isSignUp, setIsSignUp] = useState(true);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    authClient.getSession().then((result) => {
      if (result.data?.session && result.data?.user) {
        setSession(result.data.session);
        setUser(result.data.user);
      }
      setLoading(false);
    });
  }, []);

  const handleSubmit = async (e) => {
    e.preventDefault();
    const result = isSignUp
      ? await authClient.signUp.email({ name: email.split('@')[0] || 'User', email, password })
      : await authClient.signIn.email({ email, password });

    if (result.error) {
      alert(result.error.message);
      return;
    }

    const sessionResult = await authClient.getSession();
    if (sessionResult.data?.session && sessionResult.data?.user) {
      setSession(sessionResult.data.session);
      setUser(sessionResult.data.user);
    }
  };

  const handleSignOut = async () => {
    await authClient.signOut();
    setSession(null);
    setUser(null);
  };

  if (loading) return <div>Loading...</div>;

  if (session && user) {
    return (
      <div>
        <h1>Logged in as {user.email}</h1>
        <button onClick={handleSignOut}>Sign Out</button>
      </div>
    );
  }

  return (
    <form onSubmit={handleSubmit}>
      <h1>{isSignUp ? 'Sign Up' : 'Sign In'}</h1>
      <input
        type="email"
        placeholder="Email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        required
      />
      <input
        type="password"
        placeholder="Password"
        value={password}
        onChange={(e) => setPassword(e.target.value)}
        required
      />
      <button type="submit">{isSignUp ? 'Sign Up' : 'Sign In'}</button>
      <p>
        {isSignUp ? (
          <>
            Already have an account?{' '}
            <a
              href="#"
              onClick={(e) => {
                e.preventDefault();
                setIsSignUp(false);
              }}
            >
              Sign in
            </a>
          </>
        ) : (
          <>
            Don't have an account?{' '}
            <a
              href="#"
              onClick={(e) => {
                e.preventDefault();
                setIsSignUp(true);
              }}
            >
              Sign up
            </a>
          </>
        )}
      </p>
    </form>
  );
}
```

## ดูผู้ใช้ของคุณในฐานข้อมูล

เมื่อผู้ใช้สมัครสมาชิก โปรไฟล์ของพวกเขาจะถูกซิงก์ไปยังฐานข้อมูล Neon ของคุณในตาราง `neon_auth.user`

สืบค้นตารางผู้ใช้ใน SQL Editor เพื่อดูผู้ใช้ใหม่ของคุณ:

```sql filename="SQL Editor"
SELECT * FROM neon_auth.user;
```
