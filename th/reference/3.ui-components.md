# เอกสารอ้างอิง UI Components

เอกสารอ้างอิงฉบับย่อสำหรับคอมโพเนนต์ UI ของ Managed Better Auth

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

เอกสารอ้างอิงฉบับย่อสำหรับคอมโพเนนต์ UI ของ Managed Better Auth จาก `@neondatabase/auth-ui` คอมโพเนนต์เหล่านี้สร้างด้วย [Better Auth UI](https://legacy.better-auth-ui.com/) และทำงานร่วมกับ Managed Better Auth

**หมายเหตุ: การย้ายจาก import แบบเก่า**

เวอร์ชันเก่าเคย re-export UI จาก `@neondatabase/auth/react/ui` และ `@neondatabase/neon-js/auth/react/ui` entrypoint เหล่านี้ถูก deprecated แล้วและจะถูกนำออกใน major version ถัดไป ให้ติดตั้ง `@neondatabase/auth-ui` โดยตรงและรัน codemod เพื่ออัปเดต import ที่มีอยู่:

```bash
npx -p @neondatabase/auth neon-auth-codemod --write <path>
```

## การติดตั้ง

```bash
npm install @neondatabase/neon-js@latest @neondatabase/auth-ui
```

## การตั้งค่า Provider

ครอบแอปของคุณด้วย `NeonAuthUIProvider` เพื่อเปิดใช้งานคอมโพเนนต์ UI โดย provider รับ configuration props ที่ควบคุมว่าฟีเจอร์ใดพร้อมใช้งาน

### การตั้งค่าพื้นฐาน

```tsx
import { NeonAuthUIProvider } from '@neondatabase/auth-ui';
import '@neondatabase/auth-ui/css';
import { authClient } from './auth';

function App() {
  return (
    <NeonAuthUIProvider authClient={authClient}>{/* Your app components */}</NeonAuthUIProvider>
  );
}
```

### Props ที่ใช้บ่อย

| Prop                         | Type                     | คำอธิบาย                                                                 | ตัวอย่าง                                                  |
| ---------------------------- | ------------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------- |
| `authClient`                 | `NeonAuthPublicApi`      | **จำเป็น** instance ของ Managed Better Auth client ของคุณ                | `authClient={authClient}`                                |
| `social.providers`           | `SocialProvider[]`       | รายการ OAuth providers ที่จะเปิดใช้งาน (เช่น Google, GitHub, Vercel)     | `social={{ providers: ['google', 'github', 'vercel'] }}` |
| `navigate`                   | `(href: string) => void` | ฟังก์ชัน navigation สำหรับ React Router                                  | `navigate={navigate}`                                    |
| `Link`                       | `ComponentType`          | คอมโพเนนต์ Link แบบกำหนดเองสำหรับ routing                                | `Link={RouterLink}`                                      |
| `localization`               | `AuthLocalization`       | ปรับแต่งข้อความ label ทั่วทั้ง UI                                        | ดูตัวอย่างด้านล่าง                                       |
| `avatar`                     | `AvatarOptions`          | การตั้งค่าการอัปโหลดและแสดง avatar                                       | `avatar={{ size: 256, extension: 'webp' }}`              |
| `additionalFields`           | `AdditionalFields`       | ฟิลด์แบบกำหนดเองสำหรับการสมัครสมาชิกและการตั้งค่าบัญชี                    | ดูตัวอย่างด้านล่าง                                       |
| `credentials.forgotPassword` | `boolean`                | เปิดใช้งานโฟลว์ลืมรหัสผ่าน                                                | `credentials={{ forgotPassword: true }}`                 |
| `magicLink`                  | `boolean`                | เปิดใช้งานตัวเลือกเข้าสู่ระบบแบบไม่ใช้รหัสผ่านด้วยเมจิกลิงก์              | `magicLink`                                              |

### เปิดใช้งาน OAuth Providers

หากต้องการเปิดใช้งานการเข้าสู่ระบบด้วย Google (หรือ OAuth provider อื่น) ให้เพิ่ม prop `social` ลงใน provider:

```tsx
import { NeonAuthUIProvider } from '@neondatabase/auth-ui';
import { authClient } from './auth';

function App() {
  return (
    <NeonAuthUIProvider
      authClient={authClient}
      social={{
        providers: ['google', 'github', 'vercel'], // Enable Google, GitHub, and Vercel sign-in
      }}
    >
      {/* Your app */}
    </NeonAuthUIProvider>
  );
}
```

**หมายเหตุ:** Google OAuth ใช้ shared credentials สำหรับ development ได้ ส่วน GitHub OAuth ต้องใช้ custom credentials prop `social.providers` ควบคุมว่าปุ่ม provider ใดจะแสดงใน UI สำหรับ production ให้ตั้งค่า OAuth credentials ใน Neon Console (**branch → Auth**) และลงทะเบียน provider redirect URIs (ดู [การตั้งค่า OAuth](https://neon.com/docs/auth/guides/setup-oauth#production-setup))

### การเชื่อมต่อ React Router

หากใช้ React Router ให้ส่งฟังก์ชัน `navigate` และคอมโพเนนต์ `Link` แบบกำหนดเอง:

```tsx
import { NeonAuthUIProvider } from '@neondatabase/auth-ui';
import { useNavigate, Link as RouterLink } from 'react-router-dom';
import { authClient } from './auth';

function App() {
  const navigate = useNavigate();

  return (
    <NeonAuthUIProvider
      authClient={authClient}
      navigate={navigate}
      Link={RouterLink}
      social={{
        providers: ['google', 'github', 'vercel'],
      }}
    >
      {/* Your app */}
    </NeonAuthUIProvider>
  );
}
```

### ตัวอย่างการปรับแต่ง

**ปรับแต่ง localization:**

```tsx
<NeonAuthUIProvider
  authClient={authClient}
  localization={{
    SIGN_IN: 'Welcome Back',
    SIGN_UP: 'Create Account',
    FORGOT_PASSWORD: 'Forgot Password?',
  }}
>
```

**ฟิลด์สมัครสมาชิกแบบกำหนดเอง:**

```tsx
<NeonAuthUIProvider
  authClient={authClient}
  additionalFields={{
    company: {
      label: 'Company',
      placeholder: 'Your company name',
      type: 'string',
      required: false,
    },
  }}
  signUp={{
    fields: ['name', 'company'],
  }}
>
```

สำหรับเอกสาร prop แบบครบถ้วน โปรดดู TypeScript types ที่ export จาก `@neondatabase/neon-js/auth/react`

## คอมโพเนนต์หลัก

### คอมโพเนนต์ Authentication

| Component    | จุดประสงค์                                             | Props หลัก   | เอกสาร                                                               |
| ------------ | ------------------------------------------------- | ---------- | ------------------------------------------------------------------- |
| `<AuthView>` | UI auth แบบ all-in-one พร้อมฟอร์มเข้าสู่ระบบและสมัครสมาชิก | `pathname` | [auth-view](https://legacy.better-auth-ui.com/components/auth-view) |

`<AuthView>` รับได้ทั้ง `path` และ `pathname` ใช้ `path` สำหรับชื่อ view แบบเดี่ยว (เช่น `"sign-in"`) ใช้ `pathname` สำหรับ URL path แบบเต็ม (เช่น `"/auth/sign-in"`) โดยคอมโพเนนต์จะดึง segment สุดท้ายให้อัตโนมัติ

**คอมโพเนนต์ฟอร์ม:** มี `<SignUpForm>`, `<SignInForm>`, `<ForgotPasswordForm>`, `<ResetPasswordForm>` และ `<AuthCallback>` ให้ใช้งานด้วย `<AuthView>` มีฟังก์ชันเข้าสู่ระบบและสมัครสมาชิกพร้อมลิงก์ "create account" สำหรับสลับระหว่างฟอร์ม ใช้คอมโพเนนต์ฟอร์มแยกกันหากคุณต้องการควบคุม layout มากขึ้น

**ปุ่ม OAuth Provider:** ปุ่ม OAuth provider (Google, GitHub, Vercel เป็นต้น) จะแสดงใน `<AuthView>` โดยอัตโนมัติเมื่อตั้งค่าผ่าน prop `social.providers` ปุ่ม OAuth จะไม่แสดงในคอมโพเนนต์ `<SignInForm>` หรือ `<SignUpForm>` แบบ standalone

### คอมโพเนนต์ User Management

| Component            | จุดประสงค์                                | Props หลัก              | เอกสาร                                                                                    |
| -------------------- | ------------------------------------- | ---------------------- | --------------------------------------------------------------------------------------- |
| `<UserButton>`       | เมนู dropdown ของผู้ใช้พร้อม avatar       | -                      | [user-button](https://legacy.better-auth-ui.com/components/user-button)                 |
| `<UserAvatar>`       | รูปโปรไฟล์พร้อมรองรับ Gravatar             | `user`, `size`         | [user-avatar](https://legacy.better-auth-ui.com/components/user-avatar)                 |
| `<SignedIn>`         | render แบบมีเงื่อนไขเมื่อเข้าสู่ระบบแล้ว    | `children`, `fallback` | [signed-in](https://legacy.better-auth-ui.com/components/signed-in)                     |
| `<SignedOut>`        | render แบบมีเงื่อนไขเมื่อออกจากระบบ        | `children`, `fallback` | [signed-out](https://legacy.better-auth-ui.com/components/signed-out)                   |
| `<RedirectToSignIn>` | helper สำหรับ redirect ไปหน้าเข้าสู่ระบบ   | `redirectTo`           | [redirect-to-sign-in](https://legacy.better-auth-ui.com/components/redirect-to-sign-in) |
| `<RedirectToSignUp>` | helper สำหรับ redirect ไปหน้าสมัครสมาชิก   | `redirectTo`           | [redirect-to-sign-up](https://legacy.better-auth-ui.com/components/redirect-to-sign-up) |

## Styling

เลือกวิธี import ตามการตั้งค่าโปรเจ็กต์ของคุณ:

### ไม่ใช้ Tailwind CSS

หากโปรเจ็กต์ของคุณไม่ได้ใช้ Tailwind CSS ให้ import CSS bundle สำเร็จรูป:

```typescript
// In your root layout or app entry point
import '@neondatabase/auth-ui/css';
```

ไฟล์นี้รวม style ที่จำเป็นทั้งหมด (~47KB minified) โดยไม่ต้องตั้งค่าเพิ่มเติม

### ใช้ Tailwind CSS v4

หากโปรเจ็กต์ของคุณใช้ Tailwind CSS v4 อยู่แล้ว ให้ import CSS ที่พร้อมสำหรับ Tailwind เพื่อหลีกเลี่ยง style ซ้ำ:

```css
/* In your main CSS file (for example, globals.css) */
@import 'tailwindcss';
@import '@neondatabase/auth-ui/tailwind';
```

การ import นี้จะนำเข้าเฉพาะ theme variables จากนั้น Tailwind build ของคุณจะสร้าง utility classes

**คำเตือน:** ห้าม import ทั้งสอง path พร้อมกัน เพราะจะทำให้เกิด style ซ้ำ

สำหรับตัวเลือกการปรับแต่ง โปรดดูรายละเอียด **Styling** ภายในหน้าเอกสารของแต่ละคอมโพเนนต์ Better Auth UI ตัวอย่าง: [การจัด style ของ Auth View](https://legacy.better-auth-ui.com/components/auth-view#styling)

## ตัวอย่างการใช้งาน

### Auth Flow พื้นฐาน

```tsx
import { AuthView } from '@neondatabase/auth-ui';
import '@neondatabase/auth-ui/css';

function App() {
  return <AuthView pathname="sign-in" />;
}
```

### Next.js App Router

สำหรับ Next.js App Router ให้ใช้ catch-all route เพื่อรองรับ auth views ทั้งหมด สร้าง `app/auth/[path]/page.tsx`:

```tsx
import { AuthView } from '@neondatabase/auth-ui';
import { authViewPaths } from '@neondatabase/auth-ui/server';

export const dynamicParams = false;

export function generateStaticParams() {
  return Object.values(authViewPaths).map((path) => ({ path }));
}

export default async function AuthPage({
  params,
}: {
  params: Promise<{ path: string }>;
}) {
  const { path } = await params;

  return (
    <main className="flex min-h-screen items-center justify-center p-4">
      <AuthView path={path} />
    </main>
  );
}
```

### เมนูผู้ใช้

```tsx
import { UserButton } from '@neondatabase/auth-ui';
import { authClient } from './auth';

function Header() {
  return (
    <header>
      <UserButton authClient={authClient} />
    </header>
  );
}
```

### Route ที่มีการป้องกัน

```tsx
import { SignedIn, SignedOut, RedirectToSignIn } from '@neondatabase/auth-ui';

function Dashboard() {
  return (
    <>
      <SignedIn>
        <h1>Dashboard</h1>
      </SignedIn>
      <SignedOut>
        <RedirectToSignIn />
      </SignedOut>
    </>
  );
}
```
