# การจัดการผู้ใช้

อัปเดตโปรไฟล์ เปลี่ยนรหัสผ่าน และจัดการการตั้งค่าบัญชี

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

จัดการโปรไฟล์ผู้ใช้และการตั้งค่าบัญชีหลังจากผู้ใช้เข้าสู่ระบบ คู่มือนี้ครอบคลุม:

- การอัปเดตข้อมูลโปรไฟล์ (ชื่อ, รูปภาพ, หมายเลขโทรศัพท์)
- การเปลี่ยนรหัสผ่านอย่างปลอดภัย
- การเปลี่ยนอีเมลพร้อมการยืนยัน
- การลบบัญชีผู้ใช้

## อัปเดตโปรไฟล์ผู้ใช้

อัปเดตฟิลด์โปรไฟล์ผู้ใช้ เช่น ชื่อ รูปภาพ หรือหมายเลขโทรศัพท์ด้วย `updateUser()`:

```jsx filename="src/App.jsx"
import { authClient } from './auth';

const handleUpdateProfile = async (e) => {
  e.preventDefault();
  setMessage('');

  try {
    const { data, error } = await authClient.updateUser({
      name: 'New Name',
    });

    if (error) throw error;

    // Refresh session to get updated user data
    const sessionResult = await authClient.getSession();
    if (sessionResult.data?.session) {
      setUser(sessionResult.data.session.user);
      setMessage('Profile updated successfully!');
    }
  } catch (error) {
    setMessage(error?.message || 'Update failed');
  }
};
```

### ฟิลด์โปรไฟล์ที่พร้อมใช้งาน

คุณสามารถอัปเดตฟิลด์เหล่านี้ด้วย `updateUser()`:

- `name` (string) - ชื่อที่แสดงของผู้ใช้

**หมายเหตุ:** ปัจจุบันยังไม่รองรับการเปลี่ยนอีเมล หากต้องการรีเซ็ตรหัสผ่านที่ลืม โปรดดู [การรีเซ็ตรหัสผ่าน](https://neon.com/docs/auth/guides/password-reset)

## เปลี่ยนรหัสผ่าน

เปลี่ยนรหัสผ่านของผู้ใช้ขณะที่ผู้ใช้เข้าสู่ระบบอยู่ด้วย `changePassword()` โดยต้องใช้รหัสผ่านปัจจุบันเพื่อความปลอดภัย:

```jsx filename="src/App.jsx"
import { authClient } from './auth';

const handleChangePassword = async (e) => {
  e.preventDefault();
  setMessage('');

  try {
    const { data, error } = await authClient.changePassword({
      newPassword: 'new-secure-password',
      currentPassword: 'current-password',
    });

    if (error) throw error;
    setMessage('Password changed successfully!');
  } catch (error) {
    setMessage(error?.message || 'Password change failed');
  }
};
```

### ยกเลิกเซสชันอื่น

เลือกออกจากระบบอุปกรณ์อื่นทั้งหมดพร้อมกับการเปลี่ยนรหัสผ่านได้:

```jsx filename="src/App.jsx"
const { data, error } = await authClient.changePassword({
  newPassword: 'new-secure-password',
  currentPassword: 'current-password',
  revokeOtherSessions: true, // Signs out all other devices
});
```

**หมายเหตุ:** หากผู้ใช้ลืมรหัสผ่าน ให้ใช้โฟลว์รีเซ็ตรหัสผ่าน (`requestPasswordReset()` และ `resetPassword()`) แทน โปรดดู [การรีเซ็ตรหัสผ่าน](https://neon.com/docs/auth/guides/password-reset)

## รีเฟรชข้อมูลผู้ใช้

หลังจากอัปเดตข้อมูลโปรไฟล์ ให้รีเฟรชเซสชันเพื่อรับข้อมูลผู้ใช้ล่าสุด:

```jsx filename="src/App.jsx"
import { authClient } from './auth';

const refreshUser = async () => {
  const { data } = await authClient.getSession();
  if (data?.session) {
    setUser(data.session.user);
  }
};
```

เรียก `refreshUser()` หลังจากเรียก `updateUser()` สำเร็จ เพื่อให้แน่ใจว่า UI ของคุณแสดงข้อมูลล่าสุด

- [การรีเซ็ตรหัสผ่าน](https://neon.com/docs/auth/guides/password-reset): รีเซ็ตรหัสผ่านที่ลืม
- [การยืนยันอีเมล](https://neon.com/docs/auth/guides/email-verification): ยืนยันอีเมล
- [โฟลว์การยืนยันตัวตน](https://neon.com/docs/auth/authentication-flow): ทำความเข้าใจโฟลว์การยืนยันตัวตน
