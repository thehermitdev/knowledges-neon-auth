> สรุป: การยืนยันอีเมลของ Managed Better Auth ใช้ยืนยันว่าผู้ใช้เป็นเจ้าของอีเมลที่นำมาลงทะเบียนจริง โดยรองรับทั้งรหัส OTP แบบตัวเลข (ใช้งานได้กับผู้ให้บริการอีเมลแบบใช้ร่วมกันหรือแบบกำหนดเอง) และลิงก์ยืนยันที่ผู้ใช้คลิกเพื่อดำเนินการต่อ (ต้องใช้ผู้ให้บริการอีเมลแบบกำหนดเอง) ทั้งสองวิธีจะหมดอายุหลังจาก 15 นาทีและสามารถส่งใหม่ได้ คุณสามารถกำหนดให้การยืนยันเป็นข้อบังคับหรือเป็นทางเลือกใน Neon Console ซึ่งจะควบคุมว่าผู้ใช้ที่ยังไม่ได้ยืนยันอีเมลสามารถเข้าสู่ระบบได้หรือไม่

# การยืนยันอีเมล

ยืนยันอีเมลของผู้ใช้ระหว่างการสมัครสมาชิกหรือการสร้างบัญชี

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

การยืนยันอีเมลช่วยให้แน่ใจว่าผู้ใช้เป็นเจ้าของอีเมลที่นำมาลงทะเบียนจริง ชื่อแอปพลิเคชันที่แสดงในอีเมลเหล่านี้สามารถกำหนดแยกตามแต่ละบรานช์ได้ ดูรายละเอียดที่ [ชื่อแอปพลิเคชัน](https://neon.com/docs/auth/production-checklist#application-name)

Managed Better Auth รองรับวิธีการยืนยันสองแบบ:

- **รหัสยืนยัน** (ผู้ใช้กรอกรหัสตัวเลขที่ได้รับทางอีเมล) - ใช้งานได้กับผู้ให้บริการอีเมลแบบใช้ร่วมกันหรือแบบกำหนดเอง
- **ลิงก์ยืนยัน** (ผู้ใช้คลิกลิงก์ในอีเมล) - ต้องใช้ผู้ให้บริการอีเมลแบบกำหนดเอง

**หมายเหตุ:** ลิงก์ยืนยันต้องใช้ [ผู้ให้บริการอีเมลแบบกำหนดเอง](https://neon.com/docs/auth/production-checklist#email-provider) หากคุณกำลังใช้ผู้ให้บริการอีเมลแบบใช้ร่วมกัน ให้ใช้รหัสยืนยันแทน

## เปิดใช้งานการยืนยันอีเมล

ในหน้า **Settings** → **Auth** ของโปรเจ็กต์ ให้เปิดใช้งาน **Sign-up with Email** และ **Verify at Sign-up** จากนั้นเลือกวิธีการยืนยันที่ต้องการ

![การตั้งค่าการยืนยันอีเมลใน Neon Console](https://neon.com/docs/auth/email-verification-settings.png)

## ลิงก์ยืนยัน

ลิงก์ยืนยันต้องใช้ผู้ให้บริการอีเมลแบบกำหนดเอง ดูวิธีตั้งค่าได้ที่ [การตั้งค่าผู้ให้บริการอีเมล](https://neon.com/docs/auth/production-checklist#email-provider)

เมื่อผู้ใช้คลิกลิงก์ยืนยันในอีเมล เซิร์ฟเวอร์ Managed Better Auth จะจัดการการยืนยันและ redirect ผู้ใช้กลับมายังแอปพลิเคชันของคุณ จากนั้นแอปจะตรวจสอบเซสชันใหม่และแสดง UI ที่เหมาะสม

### 1. ตรวจสอบเซสชันเมื่อคอมโพเนนต์ mount

เพิ่มการตรวจสอบเซสชันเมื่อคอมโพเนนต์ mount เพื่อให้ตรวจพบเมื่อผู้ใช้กลับมาหลังจากคลิกลิงก์ยืนยัน:

```jsx filename="src/App.jsx" {9-14}
import { useEffect, useState } from 'react';
import { authClient } from './auth';

export default function App() {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    authClient.getSession().then(({ data }) => {
      if (data?.session) {
        setUser(data.session.user);
      }
      setLoading(false);
    });
  }, []);
}
```

### 2. จัดการการสมัครสมาชิกที่ต้องมีการยืนยัน

หลังจากเรียก `signUp.email()` ให้ตรวจสอบว่าจำเป็นต้องยืนยันหรือไม่ แล้วแสดงข้อความให้ผู้ใช้ทราบ:

```jsx {16-18} filename="src/App.jsx"
const handleSignUp = async (e) => {
  e.preventDefault();
  setMessage('');

  try {
    const { data, error } = await authClient.signUp.email({
      email,
      password,
      name: name || email.split('@')[0] || 'User',
    });

    if (error) throw error;

    // Check if email verification is required
    if (data?.user && !data.user.emailVerified) {
      setMessage('Check your email for a verification link!');
    } else {
      setMessage('Account created! Please sign in.');
    }
  } catch (error) {
    setMessage(error?.message || 'An error occurred');
  }
};
```

### 3. ตรวจสอบสถานะการยืนยัน

เข้าถึงฟิลด์ `emailVerified` จากออบเจ็กต์ผู้ใช้:

```jsx {3} filename="src/App.jsx"
const { data } = await authClient.getSession();

if (data?.session?.user && !data.session.user.emailVerified) {
  // Show verification prompt or restrict features
  console.log('Please verify your email to continue');
}
```

## รหัสยืนยัน

หากคุณต้องการใช้รหัสยืนยัน ผู้ใช้จะได้รับรหัสตัวเลขทางอีเมลและนำรหัสนั้นมากรอกในแอปพลิเคชันของคุณ แอปจะสลับระหว่างฟอร์มการยืนยันตัวตนกับฟอร์มยืนยันอีเมล

### 1. เพิ่ม state สำหรับการยืนยัน

เพิ่ม state เพื่อติดตามว่าควรแสดงฟอร์มใด:

```jsx filename="src/App.jsx"
const [step, setStep] = useState('auth'); // 'auth' or 'verify'
const [code, setCode] = useState('');
```

### 2. จัดการการยืนยันด้วยรหัส

สร้าง handler สำหรับการยืนยันด้วยรหัส:

```jsx {6-9} filename="src/App.jsx"
const handleVerify = async (e) => {
  e.preventDefault();
  setMessage('');

  try {
    const { data, error } = await authClient.emailOtp.verifyEmail({
      email,
      otp: code,
    });

    if (error) throw error;

    // Check if auto-sign-in is enabled (default behavior)
    if (data?.session) {
      setUser(data.session.user);
      setStep('auth');
    } else {
      setMessage('Email verified! You can now sign in.');
      setStep('auth');
      setIsSignUp(false);
      setCode('');
    }
  } catch (error) {
    setMessage(error?.message || 'An error occurred');
  }
};
```

### 3. แสดงฟอร์มยืนยัน

เมื่อ `step` เป็น `'verify'` ให้แสดงฟอร์มยืนยัน:

```jsx filename="src/App.jsx"
if (step === 'verify') {
  return (
    <div>
      <h1>Verify Your Email</h1>
      <p>Enter the code sent to {email}</p>
      <form onSubmit={handleVerify}>
        <input
          type="text"
          placeholder="Verification code"
          value={code}
          onChange={(e) => setCode(e.target.value)}
          required
        />
        <button type="submit">Verify</button>
      </form>
      {message && <p>{message}</p>}
    </div>
  );
}
```

### 4. สลับไปยังขั้นตอนยืนยันหลังสมัครสมาชิก

หลังจากเรียก `signUp.email()` ให้สลับไปยังขั้นตอนยืนยัน:

```jsx {3} filename="src/App.jsx"
if (data?.user && !data.user.emailVerified) {
  setMessage('Check your email for a verification code');
  setStep('verify'); // Switch to verification form
}
```

<summary>ตัวอย่างฉบับสมบูรณ์: App.jsx พร้อมการยืนยันด้วยรหัส</summary>

ต่อไปนี้คือไฟล์ `App.jsx` ฉบับสมบูรณ์แบบขั้นต่ำ ซึ่งมีฟังก์ชันการสมัครสมาชิก การเข้าสู่ระบบ และการยืนยันด้วยรหัส:

```jsx filename="src/App.jsx"
import { useState, useEffect } from 'react';
import { authClient } from './auth';
import './App.css';

export default function App() {
  const [session, setSession] = useState(null);
  const [user, setUser] = useState(null);
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(true);
  const [message, setMessage] = useState('');
  const [step, setStep] = useState('auth'); // 'auth' or 'verify'
  const [code, setCode] = useState('');
  const [isSignUp, setIsSignUp] = useState(true);

  useEffect(() => {
    authClient.getSession().then((result) => {
      if (result.data?.session && result.data?.user) {
        setSession(result.data.session);
        setUser(result.data.user);
      }
      setLoading(false);
    });
  }, []);

  const handleSignUp = async (e) => {
    e.preventDefault();
    setMessage('');
    const { data, error } = await authClient.signUp.email({
      email,
      password,
      name: email.split('@')[0] || 'User',
    });
    if (error) {
      setMessage(error.message);
      return;
    }
    if (data?.user && !data.user.emailVerified) {
      setMessage('Check your email for a verification code');
      setStep('verify'); // Switch to verification form
    } else {
      const sessionResult = await authClient.getSession();
      if (sessionResult.data?.session && sessionResult.data?.user) {
        setSession(sessionResult.data.session);
        setUser(sessionResult.data.user);
      }
    }
  };

  const handleSignIn = async (e) => {
    e.preventDefault();
    setMessage('');
    const { data, error } = await authClient.signIn.email({ email, password });
    if (error) {
      setMessage(error.message);
      return;
    }
    if (data?.session && data?.user) {
      setSession(data.session);
      setUser(data.user);
    }
  };
  const handleVerify = async (e) => {
    e.preventDefault();
    setMessage('');
    try {
      const { data, error } = await authClient.emailOtp.verifyEmail({
        email,
        otp: code,
      });
      if (error) throw error;
      if (data?.session) {
        setSession(data.session);
        setUser(data.session.user);
        setStep('auth');
      } else {
        setMessage('Email verified! You can now sign in.');
        setStep('auth');
        setIsSignUp(false);
        setCode('');
      }
    } catch (error) {
      setMessage(error?.message || 'An error occurred');
    }
  };

  const handleSignOut = async () => {
    await authClient.signOut();
    setSession(null);
    setUser(null);
  };

  if (loading) return <div>Loading...</div>;

  if (session && user) {
    return (
      <div>
        <h1>Logged in as {user.email}</h1>
        <button onClick={handleSignOut}>Sign Out</button>
      </div>
    );
  }
  if (step === 'verify') {
    return (
      <div>
        {' '}
        <h1>Verify Your Email</h1>
        <p>Enter the code sent to {email}</p>
        <form onSubmit={handleVerify}>
          {' '}
          <input
            type="text"
            placeholder="Verification code"
            value={code}
            onChange={(e) => setCode(e.target.value)}
            required
          />{' '}
          <button type="submit">Verify</button>
        </form>{' '}
        {message && <p>{message}</p>}
      </div>
    );
  }

  return (
    <div>
      <h1>{isSignUp ? 'Sign Up' : 'Sign In'}</h1>
      {message && <p>{message}</p>}
      <form onSubmit={isSignUp ? handleSignUp : handleSignIn}>
        <input
          type="email"
          placeholder="Email"
          value={email}
          onChange={(e) => setEmail(e.target.value)}
          required
        />
        <input
          type="password"
          placeholder="Password"
          value={password}
          onChange={(e) => setPassword(e.target.value)}
          required
        />
        <button type="submit">{isSignUp ? 'Sign Up' : 'Sign In'}</button>
      </form>
      <p>
        <button onClick={() => setIsSignUp(!isSignUp)}>
          {isSignUp ? 'Already have an account? Sign in' : "Don't have an account? Sign up"}
        </button>
      </p>
    </div>
  );
}
```

## การส่งอีเมลยืนยันอีกครั้ง

ทั้งลิงก์ยืนยันและรหัสยืนยันจะหมดอายุหลังจาก **15 นาที** ให้ผู้ใช้สามารถขอรายการใหม่ได้:

```jsx {3-6} filename="src/App.jsx"
const handleResend = async () => {
  try {
    const { error } = await authClient.sendVerificationEmail({
      email,
      callbackURL: window.location.origin + '/',
    });

    if (error) throw error;
    setMessage('Verification email sent! Check your inbox.');
  } catch (error) {
    setMessage(error?.message || 'An error occurred');
  }
};
```

เซิร์ฟเวอร์จะส่งรูปแบบที่คุณตั้งค่าไว้ใน Console ไม่ว่าจะเป็นลิงก์ยืนยันหรือรหัสยืนยัน

## การยืนยันแบบบังคับเทียบกับแบบไม่บังคับ

เมื่อกำหนดให้การยืนยันอีเมลเป็น **ข้อบังคับ** ในการตั้งค่า Console ผู้ใช้จะไม่สามารถเข้าสู่ระบบได้จนกว่าจะยืนยันอีเมล เมื่อกำหนดให้การยืนยันเป็น **ทางเลือก** ผู้ใช้สามารถเข้าสู่ระบบได้ทันที แต่ฟิลด์ `emailVerified` จะยังคงเป็น `false` จนกว่าจะยืนยัน
