> ตำแหน่งของหน้านี้: Auth > Plugins > ปลั๊กอินที่รองรับ
> ดัชนีเอกสาร Neon ฉบับเต็ม: https://neon.com/docs/llms.txt

> สรุป: Managed Better Auth เปิดให้ใช้งานชุดปลั๊กอิน Better Auth บางส่วนที่ระบบจัดการให้ (Admin, Email OTP, JWT, Magic Link, Organization, Open API, Phone Number) ผ่าน Neon SDK โดยไม่ต้องติดตั้งหรือตั้งค่าปลั๊กอินโดยตรง ใช้หน้านี้เพื่อตรวจสอบว่าปลั๊กอินใดรองรับเต็มรูปแบบหรือรองรับเพียงบางส่วน และวิธีตั้งค่าผ่าน Neon Console หรือ Neon API โดยปลั๊กอิน Organization รองรับเพียงบางส่วน

# ปลั๊กอิน

ปลั๊กอิน Better Auth ที่รองรับใน Managed Better Auth

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

Managed Better Auth สร้างขึ้นบน [Better Auth](https://www.better-auth.com/) ซึ่งรองรับปลั๊กอินหลากหลายรูปแบบเพื่อขยายความสามารถด้านการยืนยันตัวตน

**ข้อมูล: ปลั๊กอินได้รับการจัดการโดย Managed Better Auth**

Managed Better Auth เป็นบริการ Better Auth แบบ **managed** คุณ **ไม่ต้องติดตั้งหรือตั้งค่าปลั๊กอิน Better Auth โดยตรง** แต่ Managed Better Auth จะเปิดให้ใช้งานเฉพาะชุดปลั๊กอินที่รองรับผ่าน Neon SDK

สำหรับปลั๊กอินที่มีการตั้งค่าใน Console (ตัวอย่างเช่น [Organization](https://neon.com/docs/auth/guides/plugins/organization)) ให้เปิด **Auth** > **Plugins** (beta) ใน Neon Console หรือใช้ Neon API โดยอาจมีตัวเลือกของปลั๊กอินเพิ่มเติมในอนาคต ดู [โรดแมป Managed Better Auth](https://neon.com/docs/auth/roadmap)

ปัจจุบัน Managed Better Auth รองรับปลั๊กอิน Better Auth ต่อไปนี้:
