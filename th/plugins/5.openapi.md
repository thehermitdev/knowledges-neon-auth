> สรุป: OpenAPI plugin สำหรับ Managed Better Auth เปิดใช้งานมาโดยค่าเริ่มต้น และมี UI เอกสารอ้างอิง API แบบ interactive ที่ขับเคลื่อนด้วย Scalar ที่ `/reference` รวมถึง endpoint สคีมา JSON ของ OpenAPI 3.x ที่ `/open-api/generate-schema` ใช้เพื่อเรียกดูและทดสอบ auth endpoints แบบ live (session, user, organization, admin) กับฐานข้อมูลของคุณโดยตรง หรือ import spec ไปยัง Postman, Insomnia หรือ Scalar SDK generator เพื่อสร้าง client แบบ type-safe สำหรับภาษาที่ไม่มี Managed Better Auth SDK โดยเฉพาะ

# Open API

เอกสาร API แบบ interactive และการสร้าง client

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

Managed Better Auth สร้างขึ้นบน [Better Auth](https://www.better-auth.com/) และมาพร้อม Open API plugin ที่เปิดใช้งานโดยค่าเริ่มต้น คุณไม่จำเป็นต้องติดตั้งหรือตั้งค่าด้วยตนเอง

OpenAPI plugin มีความสามารถหลักสองอย่าง:

1. **UI เอกสารอ้างอิง API** แบบ interactive (ขับเคลื่อนด้วย [Scalar](https://scalar.com/)) สำหรับสำรวจและทดสอบ Managed Better Auth endpoints ทั้งหมดที่ใช้งานได้
2. **endpoint ของ JSON Schema** ที่คุณสามารถใช้สร้าง client แบบ type-safe สำหรับแอปพลิเคชันของคุณ

## ข้อกำหนดเบื้องต้น

- โปรเจ็กต์ Neon ที่ **เปิดใช้งาน Auth** แล้ว

## การเข้าถึงเอกสารอ้างอิง API

คุณสามารถดูเอกสารแบบ interactive สำหรับโปรเจ็กต์ของคุณโดยเพิ่ม `/reference` ต่อท้าย Managed Better Auth URL

**รูปแบบ URL:**

```
<YOUR_NEON_AUTH_URL>/reference
```

**ตัวอย่าง:**
`https://ep-xxx.aws.neon.tech/neondb/auth/reference`

Interface นี้ช่วยให้คุณ:

- เรียกดู endpoints ทั้งหมดที่ใช้งานได้ (จัดกลุ่มตาม Core, Session, User, Plugins เป็นต้น)
- ดู request และ response schemas
- **"Try it out"**: ส่ง API requests จริงไปยังฐานข้อมูลของคุณโดยตรงจากเบราว์เซอร์

![เอกสารอ้างอิง Open API ของ Managed Better Auth](https://neon.com/docs/auth/openapi-reference.png)

**หมายเหตุ: การทดสอบ endpoints**

เมื่อใช้ฟีเจอร์ "Try it out" คุณกำลังโต้ตอบกับฐานข้อมูลจริงของคุณ โปรดระวังเมื่อทดสอบ endpoints ที่แก้ไขหรือลบข้อมูล (เช่น `admin.banUser` หรือ `organization.delete`)

## สคีมา JSON

หากคุณต้องการ specification แบบ raw ของ OpenAPI 3.x (ตัวอย่างเช่น เพื่อนำเข้า Postman หรือ Insomnia) สามารถเข้าถึงได้ที่ endpoint `/open-api/generate-schema`

**รูปแบบ URL:**

```
<YOUR_NEON_AUTH_URL>/open-api/generate-schema
```

Endpoint นี้จะคืนออบเจ็กต์ JSON มาตรฐานที่อธิบาย authentication API ของคุณ

## การสร้าง API clients

หนึ่งในกรณีการใช้งานที่มีประโยชน์มากที่สุดของ OpenAPI plugin คือการสร้าง API clients แบบ type-safe สำหรับภาษาที่ยังไม่มี Managed Better Auth SDK โดยเฉพาะ หรือสำหรับ integration ฝั่งเซิร์ฟเวอร์ที่คุณต้องการใช้ raw fetch calls

### ใช้ Scalar SDK generator

หากคุณใช้ Next.js คุณสามารถเข้าถึงหน้าเอกสารอ้างอิง OpenAPI ที่ `/api/auth/reference` ในแอปพลิเคชันของคุณได้ เมื่อตั้งค่า Managed Better Auth ตาม [Next.js quick start](https://neon.com/docs/auth/quick-start/nextjs-api-only) แล้ว ต่างจากหน้าเอกสารอ้างอิงเริ่มต้นของ Managed Better Auth เวอร์ชันนี้สามารถปรับแต่งให้เข้ากับธีมของแอปพลิเคชันได้อย่างเต็มรูปแบบ และยังมีตัวเลือกเพิ่มเติม เช่น การสร้าง SDK clients หลายภาษาด้วย [เครื่องมือในตัว](https://guides.scalar.com/scalar/scalar-sdks/getting-started) ของ Scalar

## ข้อจำกัด

เนื่องจาก Managed Better Auth เป็น managed service การตั้งค่า OpenAPI จึงถูกกำหนดไว้ล่วงหน้า:

- **Path:** UI เอกสารอ้างอิงจะให้บริการที่ `/reference` เสมอ
- **Theme:** UI ใช้ธีมเริ่มต้นของ Scalar และไม่สามารถปรับแต่งได้
- **Discovery:** เอกสารอ้างอิงจะสะท้อน plugins ที่เปิดใช้งานอยู่ใน Managed Better Auth instance ของคุณโดยอัตโนมัติ
