# Email OTP

เข้าสู่ระบบและยืนยันอีเมลด้วยรหัสผ่านแบบใช้ครั้งเดียว

**หมายเหตุ: Beta**

**Managed Better Auth** อยู่ในสถานะ Beta คุณสามารถส่งความคิดเห็นผ่าน [Discord](https://discord.gg/92vNTzKDGp) หรือผ่าน [Neon Console](https://console.neon.tech/app/projects?modal=feedback)

Managed Better Auth สร้างขึ้นบน [Better Auth](https://www.better-auth.com/) และรองรับ Email OTP plugin APIs อย่างเต็มรูปแบบผ่าน Neon SDK คุณไม่จำเป็นต้องติดตั้งหรือตั้งค่า Better Auth Email OTP plugin ด้วยตนเอง

Email OTP ช่วยให้ผู้ใช้ได้รับรหัสผ่านแบบใช้ครั้งเดียว (OTP) ทางอีเมลและนำไปใช้เพื่อ:

- เข้าสู่ระบบโดยไม่ใช้รหัสผ่าน
- รีเซ็ตรหัสผ่าน
- ยืนยันอีเมลของตน (รหัสยืนยัน)

Managed Better Auth UI และ Neon SDK เป็น SDK ฝั่ง client ดังนั้นคุณเพียงเรียกใช้เมธอดของ SDK เท่านั้น การสร้างและส่ง OTP จะถูกจัดการให้อัตโนมัติ คุณไม่สามารถควบคุมรหัสที่ส่งให้ผู้ใช้ได้โดยตรง

## ข้อกำหนดเบื้องต้น

- โปรเจ็กต์ Neon ที่ **เปิดใช้งาน Auth** แล้ว
- เปิดใช้งาน **Sign-up and Sign-in with Email** ในหน้า **Settings** → **Auth** ของโปรเจ็กต์

  **หมายเหตุ: การยืนยันอีเมลระหว่างสมัครสมาชิก**

  หากต้องการใช้ Email OTP สำหรับการยืนยันตอนสมัครสมาชิก ให้เปิด **Verify at Sign-up** และเลือก **Verification code** ภายใต้ **Verification method**
  ![การตั้งค่ารหัสยืนยัน Email OTP](https://neon.com/docs/auth/email-otp.png)

## ใช้ Email OTP กับคอมโพเนนต์ UI

หากคุณใช้คอมโพเนนต์ Managed Better Auth UI ให้เปิดใช้งาน Email OTP โดยส่ง prop `emailOTP` ให้ `NeonAuthUIProvider` ซึ่งจะเปิดใช้โฟลว์ OTP ใน auth UI สำเร็จรูป

```tsx filename="app/layout.tsx"
import { authClient } from '@/lib/auth/client';
import { NeonAuthUIProvider } from '@neondatabase/auth-ui';
import './globals.css';

export default function RootLayout({ children }: Readonly<{ children: React.ReactNode }>) {
  return (
    <html lang="en">
      <body className={'antialiased'}>
        <NeonAuthUIProvider
          authClient={authClient}
          emailOTP
        >
          {children}
        </NeonAuthUIProvider>
      </body>
    </html>
  );
}
```

ตอนนี้ผู้ใช้สามารถเข้าสู่ระบบด้วย Email OTP ได้โดยเลือกตัวเลือกนี้บนหน้าจอเข้าสู่ระบบ แล้วกรอกรหัสแบบใช้ครั้งเดียวที่ส่งไปยังอีเมลของตน

![การยืนยันด้วย Email OTP](https://neon.com/docs/auth/email-otp-verification.png)

> หากคุณยังไม่ได้ตั้งค่าคอมโพเนนต์ Managed Better Auth UI โปรดดู [เอกสารอ้างอิง UI components](https://neon.com/docs/auth/reference/ui-components) และ quick start สำหรับ [Next.js](https://neon.com/docs/auth/quick-start/nextjs-api-only) หรือ [React](https://neon.com/docs/auth/quick-start/react)

## ใช้ Email OTP กับเมธอด SDK

คุณยังสามารถทำโฟลว์ OTP โดยตรงผ่าน [Neon SDK](https://neon.com/docs/reference/javascript-sdk) ได้

### ส่ง OTP

หากต้องการส่ง OTP ให้เรียก `emailOtp.sendVerificationOtp()` และระบุ `type`:

- `sign-in` - เข้าสู่ระบบโดยไม่ใช้รหัสผ่าน
- `email-verification` - ยืนยันอีเมล

```ts filename="src/send-otp.ts"
import { authClient } from './auth';

export async function sendSignInOtp(email: string) {
  const { error } = await authClient.emailOtp.sendVerificationOtp({ email, type: 'sign-in' });

  if (error) throw error;
}
```

> สำหรับรายละเอียดเพิ่มเติม โปรดดู [Send verification OTP code](https://neon.com/docs/reference/javascript-sdk#auth-sendverificationotp) ใน Neon SDK

### เข้าสู่ระบบด้วย OTP

หลังจากผู้ใช้ได้รับรหัสแล้ว ให้เข้าสู่ระบบด้วย `signIn.emailOtp()`:

```ts filename="src/sign-in-with-otp.ts"
import { authClient } from './auth';

export async function signInWithOtp(email: string, otp: string) {
  const { data, error } = await authClient.signIn.emailOtp({ email, otp });

  if (error) throw error;
  return data;
}
```

> สำหรับรายละเอียดเพิ่มเติม โปรดดู [Sign in with OTP code](https://neon.com/docs/reference/javascript-sdk#auth-signinwithemailotp) ใน Neon SDK

### ยืนยันอีเมลด้วย OTP

หากโปรเจ็กต์ของคุณเปิดใช้งานการยืนยันอีเมลด้วย **verification codes** Managed Better Auth จะส่ง OTP ระหว่างการสมัครสมาชิก

เมื่อผู้ใช้กรอกรหัสแล้ว ให้ยืนยันอีเมลด้วย `emailOtp.verifyEmail()`:

```ts filename="src/verify-email.ts"
import { authClient } from './auth';

export async function verifyEmail(email: string, otp: string) {
  const { data, error } = await authClient.emailOtp.verifyEmail({ email, otp });

  if (error) throw error;
  return data;
}
```

> สำหรับรายละเอียดเพิ่มเติม โปรดดู [Verify email with OTP code](https://neon.com/docs/reference/javascript-sdk#auth-verifyemail) ใน Neon SDK

ดู walkthrough แบบครบถ้วนได้ที่ [คู่มือการยืนยันอีเมล](https://neon.com/docs/auth/guides/email-verification)

### ตรวจสอบ OTP (ไม่บังคับ)

หากคุณต้องการตรวจสอบความถูกต้องของ OTP โดยยังไม่ดำเนินโฟลว์ให้เสร็จ (ตัวอย่างเช่น ตรวจสอบรหัสก่อนเปิดใช้งาน UI ที่มีความอ่อนไหว) คุณสามารถใช้ `emailOtp.checkVerificationOtp()`:

```ts filename="src/otp.ts"
import { authClient } from './auth';

export async function isOtpValid(email: string, otp: string) {
  const { data, error } = await authClient.emailOtp.checkVerificationOtp({
    email,
    otp,
    type: 'sign-in',
  });

  if (error) throw error;
  return Boolean(data?.success);
}
```

> สำหรับรายละเอียดเพิ่มเติม โปรดดู [Check verification OTP code](https://neon.com/docs/reference/javascript-sdk#auth-checkverificationotp) ใน Neon SDK

## รีเซ็ตรหัสผ่านด้วย OTP

คุณยังสามารถใช้ Email OTP เพื่อทำโฟลว์รีเซ็ตรหัสผ่านได้ โดยใช้เมธอด `authClient.forgetPassword.emailOtp` เพื่อส่ง OTP สำหรับรีเซ็ตรหัสผ่านไปยังอีเมลของผู้ใช้

```ts filename="src/send-reset-otp.ts"
import { authClient } from './auth';

export async function sendPasswordResetOtp(email: string) {
  const { error } = await authClient.forgetPassword.emailOtp({ email });
  if (error) throw error;
}
```

เมื่อผู้ใช้ได้รับ OTP แล้ว ให้ตรวจสอบด้วย `authClient.emailOtp.checkVerificationOtp()` โดยตั้งค่า `type` เป็น `forget-password`

```ts filename="src/verify-reset-otp.ts"
import { authClient } from './auth';

export async function verifyPasswordResetOtp(email: string, otp: string) {
  const { data, error } = await authClient.emailOtp.checkVerificationOtp({
    email,
    otp,
    type: 'forget-password',
  });

  if (error) throw error;
  return Boolean(data?.success);
}
```

สุดท้าย ให้รีเซ็ตรหัสผ่านของผู้ใช้ด้วย `authClient.emailOtp.resetPassword()`:

```ts filename="src/reset-password.ts"
import { authClient } from './auth';

export async function resetPasswordUsingOtp(email: string, otp: string, newPassword: string) {
  const { data, error } = await authClient.emailOtp.resetPassword({
    email,
    otp,
    password: newPassword,
  });
}
```

## ข้อจำกัด

รหัส Email OTP มีเวลาจำกัดและมี rate limit

หากผู้ใช้พยายามยืนยันเกินจำนวนที่อนุญาต API จะคืน error code เช่น `TOO_MANY_ATTEMPTS` และผู้ใช้ต้องขอรหัสใหม่

## การตั้งค่าผู้ให้บริการอีเมล

สำหรับสภาพแวดล้อม production เราแนะนำอย่างยิ่งให้ใช้ผู้ให้บริการอีเมลโดยเฉพาะ ส่วน shared SMTP เริ่มต้นควรใช้เฉพาะระหว่าง development เท่านั้น โปรดดูวิธีตั้งค่าที่ [คู่มือการตั้งค่าผู้ให้บริการอีเมล](https://neon.com/docs/auth/production-checklist#email-provider)

Custom SMTP provider จะเปลี่ยนที่อยู่ผู้ส่ง แต่ยังคงส่งเทมเพลตเริ่มต้นของ Neon หากต้องการควบคุมแบรนด์อย่างเต็มรูปแบบ ให้ใช้เว็บฮุก ดู [ปรับแต่งอีเมล](https://neon.com/docs/auth/guides/customize-emails)
